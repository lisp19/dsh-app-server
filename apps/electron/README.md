# DSH Remote

An independent Electron client for DSH App Server. Run `npm run start --workspace @dsh-app-server/electron` from the repository root after installing dependencies. Enter a root HTTPS server URL and the server's launch token separately. HTTP is accepted only for `localhost`, `127.0.0.1`, or `[::1]`, including local SSH tunnels.

The client exchanges the launch token at `/?token=…` using Electron's `net.request` manual redirect event with session cookies enabled, requires a 303 response to `/` and a session cookie, then verifies `/api/app-server/info` using that session's `fetch`. The redirect is never followed. The response must identify `dsh-app-server`, protocol version `1`, and a nonempty platform string. Server certificate failures are fatal; no insecure certificate override is provided.

Each connection uses a fresh in-memory Electron session. The remote window has no preload or Node integration, uses sandboxing and context isolation, denies browser permissions and popups, and restricts navigation and network requests to the chosen server origin (plus its WebSocket transport and inline data/blob resources). Downloads from that origin use Electron's native save dialog; other download origins are rejected. The local settings preload accepts requests only from the settings window's exact main frame. Only the authenticated server URL is saved to `connection.json` in Electron's user-data directory; tokens and authentication cookies are not persisted. Language selection applies to the connection screen and native menu; the remote GUI manages its own language.

External links, account popups, and browser permissions cannot open from this client. Complete browser-based account authorization in a separate browser. The client presents the server's GUI; server filesystem paths and processes refer to the server machine. An HTTP 401 response while loading or using the GUI returns to the connection screen and requests authentication again.

Use the Connection menu to disconnect or change servers. Disconnect cancels pending authentication and clears the discarded session. Closing the client quits the desktop app without stopping the server or its sessions. Connection attempts time out after 20 seconds.

Run `npm test --workspace @dsh-app-server/electron` for Node behavioral tests. The desktop smoke test uses the root Playwright dependency and a local mock server: `xvfb-run -a npm run test:smoke --workspace @dsh-app-server/electron` on headless Linux, or omit `xvfb-run -a` when a display is available. `pack:win` builds NSIS x64, `pack:linux` builds AppImage/deb x64, and `pack:mac` builds dmg/zip for the native Mac architecture. Run these scripts with `npm run <script> --workspace apps/electron`. This configuration contains no publisher signing credentials or Apple notarization.
