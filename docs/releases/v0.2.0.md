# DSH App Server 0.2.0 — multi-platform acceptance

Remote Electron clients for Windows x64 (NSIS), Linux x64 (AppImage/deb), macOS Intel x64 and Apple Silicon arm64 (dmg/zip), plus the normally installable Linux Cordis server bundle.

The release workflow requires every native platform build and its automated smoke checks before publishing. Linux additionally exercises the packaged client with an actual Harness profile: streaming conversation, server directory browsing, WebSocket reconnect, continuing work after closing the client, and restoring history. Connection-page checks cover English/Chinese, validation, keyboard focus and supported window sizes.

Download the matching client and `dsh-app-server-server-0.2.0.tgz`; verify `SHA256SUMS`. Follow the repository README for plugin installation and SSH/HTTPS setup. Plugin compatibility: Harness `0.1.7-rc.2`, app-server protocol `1`.

Packages have no publisher signing or Apple notarization; macOS uses local ad-hoc signatures. Automated native-runner checks include launching packaged applications but do not replace interactive Windows/macOS installation acceptance. Linux model flows use deterministic fixtures, not a live model provider. This is a single-operator application, not a multi-tenant server.
