# DSH App Server v1.1.0

本版本改为独立安装 npm `@deepseek-ai/dsh@latest` 并加载其原生 GUI。桌面包不包含 DSH；服务端通过官方 CLI 创建默认 `web` profile 并添加本项目插件，不修改上游包文件，也不读取认证私有状态。`latest` 在每次安装时解析，不等同于 `next` 或永远固定的版本。

本项目网关提供固定密码和独立内存会话，原生 DSH 仅监听服务器 loopback。插件使用公开 `authenticatedUrl` API 提供私有启动信息，原生 cookie 留在服务器内存。客户端通过有随机私有 header 和 Host/origin 校验的 loopback 桥加载 GUI，支持 HTTP/WebSocket 和内置 SSH；客户端发现协议升级为 `2`。

新部署只需安装本项目依赖、打包插件、填写本机配置并执行服务 `install`，它自动准备原生运行环境。每次安装保存实际版本、解析时间及锁文件摘要。操作步骤见 [README](../../README.md) 和 [服务管理](../server-management.md)。

升级前备份完整 DSH home、本机配置和密码文件。新安装保留旧 profile 与上一份配置，仅复制用户 overlay，不自动迁移自定义插件。新旧版本共享 home；从较新的 `next` 切回较旧的 `latest` 可能需要手动数据迁移，保留旧 profile 并不能代替备份。

发布前须验证本次实际解析版本上的密码认证、原生 GUI 设置、模型流式会话、工具和目录操作、断线恢复、客户端退出后的任务/历史，以及 SSH。还须通过单元测试、Electron smoke、打包客户端检查、Windows 实际安装/升级/卸载和各原生平台构建。安装成功或构建成功不等于功能验收通过；本说明不预先声明测试已通过，准确版本和验证日期应以候选提交的实际检查记录为准。

根许可清单覆盖锁定的项目依赖，动态安装的原生服务器需另行审计。Electron、Chromium、SSH 依赖及 AppImage 运行时的原有许可和源码材料继续保留。发布资产、校验清单及平台签名限制见 [打包说明](../packaging.md)。v1.0 发布说明中的旧上游版本和补丁仅描述历史版本。
