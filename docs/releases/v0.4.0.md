# DSH App Server v0.4.0

Windows 下载 `dsh-remote-0.4.0-win-x64.exe`，退出旧客户端后安装。

## 使用

- 直连：填写 `http://服务器局域网IP:3080/` 和 app-server 密码，勾选“记住密码”。成功连接后密码使用 Windows DPAPI 加密保存；取消勾选或“忘记已保存密码”可删除。认证 cookie 仍不落盘。
- SSH：选择 SSH，填写主机 IP、SSH 端口、用户名及 SSH 密码或私钥；服务器 URL 填 `http://127.0.0.1:3080/`，并单独填写 app-server 密码。核对首次连接的主机指纹后确认。无需另开 SSH 命令；服务端须允许 TCP 转发。
- SSH 与 app-server 是两套独立认证。私钥只保存路径，不复制内容；不支持跳板机、SSH agent 或交互式 MFA。
- 服务端固定端口和密码由本机配置控制；公共脚本支持 systemd，`dsh-server port` 查询监听。部署见仓库 `docs/server-management.md`。密码文件和本机配置不包含在 Release 源码中。
- 修复远程提供商设置的 `settings are unavailable in this browser`：服务器专用 profile 应用 Host settings 兼容补丁；已有部署需运行配置安装命令并重启，单独升级客户端不能替换此服务端补丁。

## 黑屏问题状态

已加入渲染进程崩溃后返回连接页的处理。对当前 Harness 版本进行了定向诊断：选择 openai-codex、展开设置、保存及重载均未复现黑屏，包括 LAN HTTP 非安全上下文。尚未确认用户“选择该项目后”黑屏的根因，因此本版不声称已解决该问题。

当前 Harness 0.1.7-rc.2 的安装组合只有 API-key 配置 UI，未提供 Codex OAuth 授权界面；列表显示该 provider 不代表 OAuth 已连接。不要在 API-key 栏输入 ChatGPT 密码。详见 `docs/provider-compatibility.md`。

## 交付范围

本版按用户要求 build-only 发布，不运行单元、集成或端到端测试；构建和摘要校验不代表 Windows 实机连接、密码保存或 SSH 功能验收通过。已有测试预期随设置格式/控件更新但未执行。

提供 Windows x64 NSIS、Linux x64 AppImage/deb、macOS x64/arm64 dmg/zip、服务端插件 tgz，以及 SHA256SUMS 和 release-manifest.json。Windows 未签名，macOS ad-hoc 签名、未公证。

HTTP 明文连接仅用于可信 LAN/VPN；公网建议 SSH 或 HTTPS。SSH 加密到 SSH 主机为止，优先使用其 loopback 目标地址。操作系统加密无法防御已被入侵的当前账户。
