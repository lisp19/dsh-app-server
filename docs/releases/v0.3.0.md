# DSH App Server v0.3.0

## 安装与连接

Windows 下载 `dsh-remote-0.3.0-win-x64.exe`，退出旧客户端后运行安装包。连接地址填写 `http://服务器局域网IP:3080/`，启动令牌单独填写。v0.2.0 客户端不支持远程明文 HTTP，需要安装本版。

本版同时提供 Linux x64 AppImage/deb、macOS x64/arm64 dmg/zip，以及服务端插件 tgz。`SHA256SUMS` 和 `release-manifest.json` 提供大小与摘要。Windows 安装包未签名，macOS 仅 ad-hoc 签名、未公证。

## 变更

- 桌面客户端允许 HTTP 和 HTTPS 根地址，中英文连接页显示明文传输风险。
- 新增公共 systemd 安装/管理脚本 `scripts/server-control.mjs` 和配置示例 `deploy/server.example.json`，见 `docs/server-management.md`。
- `dsh-server port/status/logs/start/stop/restart` 用于本机服务操作；配置和认证信息不随源码发布。
- Token 认证、Host/origin 校验、Electron sandbox、会话隔离和 HTTPS 证书校验保持启用。

## 验收范围

按用户要求，本版采用 build-only 发布，不运行单元、集成或端到端测试。流水线仅进行依赖安装、多平台打包及发布文件完整性/摘要生成；构建成功不代表功能测试通过。已有测试预期随 HTTP 行为更新，但本轮未执行。

HTTP 不加密令牌、会话及 GUI 中输入的模型凭据，仅用于可信局域网或 VPN。请勿将 3080 端口直接暴露到公网。
