# DSH App Server 0.1.0 — baseline

Initial standalone Cordis server plugin and remote Electron client. Linux tests cover actual Harness authentication, GUI streaming, filesystem/tool execution, reconnect, continuing tasks after client exit and reopened history.

Assets: Windows x64 NSIS installer, server plugin tarball, source snapshot and SHA-256 checksums. The Windows installer is unsigned and cross-built on Linux; native Windows installation was not validated for this baseline. Deterministic model fixtures were used; no real model-provider calls were made.

Multi-platform packages are available from v0.2.0 onward.
