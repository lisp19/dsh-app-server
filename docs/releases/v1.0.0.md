# DSH App Server v1.0.0

项目自有代码采用 MIT 许可证，包含第三方许可清单、部署说明和开发文档。

- Windows、Linux、macOS Electron 客户端，支持 HTTP/HTTPS 直连与内置 SSH 转发。
- 操作系统加密保存可选登录密码，SSH 主机指纹校验，连接间隔离的内存认证会话。
- Linux Cordis 服务端插件、用户级 systemd 管理，以及远程模型设置和可选固定密码适配。
- 支持 Harness `0.1.7-rc.2`，发现协议版本 `1`。
- Windows 使用 Inno Setup `.exe` 安装程序；Linux 保留 AppImage/deb，macOS 保留 dmg/zip。

Windows v0.x 使用 NSIS，与新安装器的安装标识不同。升级前请退出客户端并卸载旧版，保留用户数据，再安装 v1.0.0。后续 Inno Setup 版本沿用稳定安装标识。

测试记录：[v1.0.0 Actions](https://github.com/lisp19/dsh-app-server/actions/runs/36227971044)，涵盖单元测试、原生 Harness 集成、四个平台构建和 Windows 安装器生命周期。

发布包含 7 个桌面分发包、1 个服务端插件包、AppImageKit/libappimage/squashfuse/XZ 的 4 个 AppImage 运行时对应源码 `.tar.gz`，以及许可证、第三方声明、npm 清单和 `appimage-runtime-sources.json`，共 16 项必需资产。发布流程另生成 `SHA256SUMS` 和 `release-manifest.json`，覆盖全部 16 项资产。

AppImage 运行时保留独立许可条件，包括 libappimage 部分代码的 GPL-2.0-only 声明；项目自有代码的 MIT 许可证不替代这些条件。对应源码及版本、摘要依据随版本提供，详见 [打包说明](../packaging.md)。

Windows 未配置发行者签名，macOS 使用 ad-hoc 签名且未经公证。该项目面向单操作者；HTTP 仅用于可信 LAN/VPN，公网连接使用 SSH 或 HTTPS。

安装与升级参考 [README](../../README.md) 和 [服务管理](../server-management.md)，安装器设计见 [打包说明](../packaging.md)。
