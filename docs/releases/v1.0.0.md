# DSH App Server v1.0.0

首个正式开源版本。项目自有代码采用 MIT 许可证，补充上游 DeepSeek Harness 归属、第三方许可说明，以及面向部署和开发的文档。

- Windows、Linux、macOS Electron 客户端，支持 HTTP/HTTPS 直连与内置 SSH 转发。
- 操作系统加密保存可选登录密码，SSH 主机指纹校验，连接间隔离的内存认证会话。
- Linux Cordis 服务端插件、用户级 systemd 管理，以及远程模型设置和可选固定密码适配。
- 支持 Harness `0.1.7-rc.2`，发现协议版本 `1`。

发布要求包含单元测试、Electron smoke、实际 Harness 集成和原生平台构建；Linux 还须检查打包客户端。最终结果以该版本对应提交的流水线记录为准，本说明不预先声明检查已通过。

客户端安装包、服务端插件、`SHA256SUMS` 和发布 manifest 由发布流程生成。Windows 未配置发行者签名，macOS 使用 ad-hoc 签名且未经公证。该项目面向单操作者；HTTP 仅用于可信 LAN/VPN，公网连接使用 SSH 或 HTTPS。

安装与升级参考 [README](../../README.md) 和 [服务管理](../server-management.md)。
